# スッキリメール — 多言語対応・国別アプリタイトル設計 v1.0

## 対応言語の選定方針
Gmail/Outlook/IMAP（Yahoo!メール・iCloud等）が実際に使われている市場を優先。
中国本土は Gmail/Outlook がアクセス制限下にあるため対象外とし、代わりに
台湾・香港ユーザー向けに zh-Hant（繁体字）を採用する。

| ロケール | 言語 | 優先度 |
|---|---|---|
| ja | 日本語（ベース） | Must（リリース時） |
| en | 英語 | Must（リリース時） |
| zh-Hant | 繁体字中国語（台湾/香港） | Should |
| ko | 韓国語 | Should |
| es | スペイン語 | Should |
| pt-BR | ポルトガル語（ブラジル） | Should |
| de | ドイツ語 | Could |
| fr | フランス語 | Could |
| id | インドネシア語 | Could |
| hi | ヒンディー語 | Could |

Must2言語（ja/en）でリリース→トラクション確認後にShould言語を追加、が[お金コレ！]等の
既存プロジェクトと同じ段階的ローカライズ方針に合わせた進め方。

## 国別アプリタイトル（ストア掲載名）

直訳ではなく「スッキリ」＝すっきり爽快・整った状態、という**体感**を各言語圏の語感で
トランスクリエーション。「削除」ではなく「整理」であることを示唆する語を選び、
"empty/delete" 系の単語（Clean out, Empty 等）は避ける（恒久削除は実装しないため、
訴求と実機能のズレを起こさない＝v1.1で修正したVision整合性の原則を踏襲）。

| ロケール | アプリタイトル | 由来・ニュアンス |
|---|---|---|
| ja | スッキリメール | ベース（既存決定） |
| en | TidyMail | tidy = 整った・片付いた。"clean/empty" ではなく整理のニュアンス |
| zh-Hant | 清爽信箱 | 「清爽」＝さっぱり爽快。「清空（空にする）」を避け削除連想を回避 |
| ko | 상쾌메일 (Sangkwae Mail) | 「상쾌」＝爽快・すっきり。日本語の語感に最も近い |
| es | Bandeja Ligera | 「軽い受信箱」。ligero=軽い、片付いた身軽さを示唆 |
| pt-BR | Caixa Leve | esと同系統。「軽い受信箱」、ブラジル語感で自然な表現 |
| de | Klarpost | klar(明瞭・すっきり)+Post(メール)の合成語。ドイツ語アプリ名に多い造語パターン |
| fr | Boîte Zen | 「禅の受信箱」。フランス語圏で好まれる"落ち着き"訴求 |
| id | Kotak Rapi | rapi=きちんとした・整頓された。インドネシア語で直感的 |
| hi | साफ़ मेल (Saaf Mail) | साफ़=清潔・すっきり。シンプルで覚えやすい |

## 実装方針
- `lib/l10n/app_<locale>.arb` でARBベースのFlutter標準l10n（`flutter_localizations` + `intl`）を使用
- `appTitle` キーは上表の値をそのまま使用（Android `strings.xml` / iOS `InfoPlist.strings` の
  ローカライズ表示名にも反映、ストア掲載名とアプリ内表示名を一致させる）
- Must2言語（ja/en）分の全画面文言をまず完訳、Should以降は`appTitle`等の主要文言のみ先行対応し
  段階的に拡張（未翻訳キーはenへフォールバック）
- 「削除」を想起させる文言（消去/空にする等）は恒久削除非実装の原則によりどの言語でも使用しない
